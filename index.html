À propos

Du design graphique au frontend moderne.

J'ai commencé par le design graphique et le webdesign avant de me passionner pour l'intégration, puis le développement frontend. Aujourd'hui, je construis des applications React et React Native métier, desktop et mobile.

Cette double culture design + dev est ma signature : je sais lire une maquette, défendre une intention UI, écrire un composant propre et penser produit. Je ne livre jamais une interface « presque pixel‑perfect ».

J'intègre l'IA dans mon workflow (Claude Code, ChatGPT) pour aller plus vite sans rien céder sur la qualité du code et l'expérience utilisateur.
